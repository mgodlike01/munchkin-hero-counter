# Манчкин — Счётчик героя

Офлайн-приложение для подсчёта силы героя в настольном «Манчкине».

- Уровень, снаряжение и временные бонусы.
- Базовая версия и режим с наёмниками и скакунами.
- Кубик D6, обучение, светлая и тёмная темы.
- Сохранение партии на устройстве.

## Установка

Скачайте `munchkin-vps-ip.tar.gz` и `SHA256SUMS.txt` из [последнего релиза](https://github.com/mgodlike01/munchkin-hero-counter/releases/latest).

[Инструкция для VPS](deploy/INSTALL.md). Нужны Ubuntu 24.04 и свободные TCP 80/8443. Мастер запускается командой `sudo bash setup.sh` из распакованного пакета.

На телефоне откройте приложение по HTTPS, дождитесь «Готово к офлайну» и добавьте его на главный экран. После первой загрузки интернет для игры не нужен.

## Запуск из исходников

Требуется Node.js 24.

```sh
npm ci
npm run dev
```

`npm run build` создаёт готовый сайт в `dist/`, `npm run check` запускает тесты и сборку.
